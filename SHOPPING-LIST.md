## 🛒 Need to Buy

### Essential (Required for Camp)

| Item | Purpose | Est. Price | Link/Notes |
|------|---------|------------|------------|
| **USB Flash Drive (16GB+)** | OCLP recovery, ROM transfer | $8-15 | Any brand works |
| **Ethernet Cables (Cat6)** | Reliable server connection | $10-20 | Get 2-3, various lengths |
| **USB-C to Thunderbolt 2 Adapter** | Connect 2019 Mac to 2012 Mac | $20-35 | Apple or Anker brand |
| **Portable Router/Access Point** | Camp WiFi network | $30-60 | TP-Link Travel Router or GL.iNet |

### Recommended (Better Experience)

| Item | Purpose | Est. Price | Link/Notes |

| **USB Hub (powered)** | Multiple peripherals | $20-35 | For MacBook Pro 2012 |
| **HDMI Cable (6ft)** | Apple TV to TV | $8-15 | If not included with TV |
| **Surge Protector/Power Strip** | Protect equipment | $15-30 | 6+ outlets |
| **Laptop Cooling Pad** | Keep server cool 24/7 | $20-40 | For MacBook running as server |
