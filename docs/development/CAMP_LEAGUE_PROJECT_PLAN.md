# Minecraft & Pokémon Camp League Project Plan

## Goal
Create a repeatable camp program for grades 1-8 that can run as a 2-day pilot camp, 3-day camp, or 5-day flagship program while keeping the experience fun, age-appropriate, and easy to staff.

## Core Success Criteria

### Minecraft
- Standard Build Battle rules
- Standard Survival Challenge rules
- Theme library
- Scoring system

### Pokémon
- Badge system
- Gym Leader system
- Tournament rules
- Trainer Passport

### Camp Operations
- Consistent awards
- Repeatable schedule
- Reusable materials

## Project Phases

### Phase 0: project setup (this week)
Focus on creating the foundation for the July pilot and the later league model.

### Phase 1: July 20-21 pilot camp
Keep the pilot intentionally simple while testing:
- activities
- timing
- age ranges
- interest level

This is not the full league yet; it is the learning and validation phase.

### Phase 2: November camp
Introduce the league model with the full Pokémon gym progression and Minecraft event structure.

### Phase 3: March camp
Refine the camp with leadership roles and team-based challenges.

### Phase 4: June flagship camp
Deliver the polished final camp experience using the complete schedule and event cadence.

## Deliverables for the July MVP

### Minecraft Build Battle
The Build Battle opens with a 10-theme library and a 40-point rubric.

Themes:
1. Pokémon Gym
2. Dream House
3. Castle
4. Treehouse
5. Zoo
6. Theme Park
7. Secret Base
8. Volcano Base
9. Underwater City
10. Space Station

Rubric:
- Creativity: 10
- Detail: 10
- Theme: 10
- Presentation: 10

Total: 40

### Minecraft Survival Challenge
Objectives and scoring:
- Build Shelter: 5
- Build Farm: 5
- Find Iron: 5
- Full Iron Armor: 10
- Find Diamonds: 10
- Build Nether Portal: 15
- Find Fortress: 20

Total: 70

### Pokémon Gym Challenge
The July pilot includes four gyms:
- Fire
- Water
- Grass
- Electric

Each gym uses a simple badge card system and a lightweight score sheet for the pilot event.

### Pokémon Scavenger Hunt
The initial hunt includes 20 tasks, such as:
- Catch a Water Type
- Catch a Flying Type
- Catch a Pokémon that evolves
- Catch a Pokémon with two types
- Catch a Pokémon beginning with "P"

## Phase 2 League Expansion

### Pokémon League
Expand to 8 gyms:
- Fire
- Water
- Grass
- Electric
- Fighting
- Psychic
- Ghost
- Dragon

Badges become entry tickets to the Pokémon Championship.

### Minecraft League
Events:
- Build Battle
- Survival Challenge
- Championship Build

Combined scores determine the Master Builder title.

## Phase 3 Refinement Camp
Adds:
- Team Captains for older campers (7th-8th grade)
- Minecraft City Build
- Pokémon Team Gym Battles

## Phase 4 Flagship Schedule
- Monday: Build Battle Qualifier
- Tuesday: Survival League
- Wednesday: Team Build Challenge
- Thursday: League Qualifiers
- Friday: Grand Finals
